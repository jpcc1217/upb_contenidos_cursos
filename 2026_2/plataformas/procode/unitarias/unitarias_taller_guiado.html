Contexto

La farmacia "Salud y Vida" necesita expandir su sistema de inventario. El sistema actual solo permite listar y crear medicamentos. Se requiere:

  • Clasificar medicamentos por categorías
  • Actualizar y eliminar medicamentos existentes
  • Validar datos de entrada
  • Manejar errores de forma profesional
  • Migrar a una base de datos real (PostgreSQL)

Paso 1: Configuración del proyecto

Crear proyecto en Spring Initializr (start.spring.io):

  • Project: Gradle - Groovy
  • Language: Java
  • Spring Boot: 4.1.x
  • Group: com.universidad
  • Artifact: farmacia-api
  • Java: 25
  • Dependencies: Spring Web, Spring Data JPA, PostgreSQL Driver, Docker Compose Support, Lombok, Validation

Crear archivo compose.yaml en la raíz del proyecto:

# /compose.yaml
services:
  postgres:
    image: postgres:18-alpine
    ports:
      - "5432:5432"
    environment:
      POSTGRES_DB: farmaciadb
      POSTGRES_USER: sa
      POSTGRES_PASSWORD: password
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U sa -d farmaciadb"]
      interval: 5s
      timeout: 5s
      retries: 5

Configurar src/main/resources/application.properties:

# /src/main/resources/application.properties

# PostgreSQL (spring-boot-docker-compose detecta compose.yaml automáticamente)
spring.datasource.url=jdbc:postgresql://localhost:5432/farmaciadb
spring.datasource.username=sa
spring.datasource.password=password

# JPA / Hibernate
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

# Virtual Threads
spring.threads.virtual.enabled=true

Verificar con ./gradlew bootRun (Docker debe estar en ejecución).

Paso 2: Entidad Categoria con Lombok

// src/main/java/com/universidad/farmacia/model/Categoria.java
package com.universidad.farmacia.model;

import jakarta.persistence.*;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

@Entity
@Getter @Setter @NoArgsConstructor
public class Categoria {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private String nombre;
    private String descripcion;

    public Categoria(String nombre, String descripcion) {
        this.nombre = nombre;
        this.descripcion = descripcion;
    }
}
Lombok genera automáticamente todos los getters, setters y el constructor vacío para evitar escribir boilerplate. Únicamente se define el constructor personalizado necesario.

Paso 3: Entidad Medicamento con relación @ManyToOne

// src/main/java/com/universidad/farmacia/model/Medicamento.java
package com.universidad.farmacia.model;

import jakarta.persistence.*;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

@Entity
@Getter @Setter @NoArgsConstructor
public class Medicamento {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    private String nombre;
    private double precio;
    private int cantidadInventario;
    
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "categoria_id")
    private Categoria categoria;

    public Medicamento(String nombre, double precio, int cantidadInventario, Categoria categoria) {
        this.nombre = nombre;
        this.precio = precio;
        this.cantidadInventario = cantidadInventario;
        this.categoria = categoria;
    }
}
La anotación @ManyToOne indica que múltiples entidades Medicamento pertenecen a una sola Categoria. La configuración LAZY asegura que la categoría solo se cargue desde la base de datos cuando sea accedida explícitamente, optimizando el rendimiento.

Paso 6: Excepción personalizada y manejo global

// src/main/java/com/universidad/farmacia/exception/ResourceNotFoundException.java
package com.universidad.farmacia.exception;

public class ResourceNotFoundException extends RuntimeException {
    public ResourceNotFoundException(String recurso, Long id) {
        super(recurso + " con ID " + id + " no fue encontrado");
    }
}
// src/main/java/com/universidad/farmacia/exception/GlobalExceptionHandler.java
package com.universidad.farmacia.exception;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.time.LocalDateTime;
import java.util.stream.Collectors;

@RestControllerAdvice
public class GlobalExceptionHandler {

    record ErrorResponse(int status, String error, String message, String timestamp) {}

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleNotFound(ResourceNotFoundException ex) {
        var body = new ErrorResponse(
            404, "Not Found", ex.getMessage(), LocalDateTime.now().toString()
        );
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(body);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponse> handleValidation(MethodArgumentNotValidException ex) {
        String mensaje = ex.getBindingResult().getFieldErrors().stream()
            .map(e -> e.getField() + ": " + e.getDefaultMessage())
            .collect(Collectors.joining(", "));
        var body = new ErrorResponse(
            400, "Bad Request", mensaje, LocalDateTime.now().toString()
        );
        return ResponseEntity.badRequest().body(body);
    }

    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<ErrorResponse> handleIllegalArgument(IllegalArgumentException ex) {
        var body = new ErrorResponse(
            400, "Bad Request", ex.getMessage(), LocalDateTime.now().toString()
        );
        return ResponseEntity.badRequest().body(body);
    }
}
La anotación @RestControllerAdvice intercepta excepciones a nivel global en la API. El record ErrorResponse define el formato estándar de error. Cada @ExceptionHandler mapea un tipo de excepción a un estado HTTP específico, garantizando respuestas consistentes.

Paso 7: Servicio CategoriaService

// src/main/java/com/universidad/farmacia/service/CategoriaService.java
package com.universidad.farmacia.service;

import com.universidad.farmacia.dto.CategoriaResponse;
import com.universidad.farmacia.dto.CreateCategoriaRequest;
import com.universidad.farmacia.exception.ResourceNotFoundException;
import com.universidad.farmacia.model.Categoria;
import com.universidad.farmacia.repository.CategoriaRepository;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class CategoriaService {

    private final CategoriaRepository repository;

    public CategoriaService(CategoriaRepository repository) {
        this.repository = repository;
    }

    public List<CategoriaResponse> obtenerTodas() {
        return repository.findAll().stream()
            .map(c -> new CategoriaResponse(c.getId(), c.getNombre(), c.getDescripcion()))
            .toList();
    }

    public CategoriaResponse crear(CreateCategoriaRequest request) {
        var categoria = new Categoria(request.nombre(), request.descripcion());
        var saved = repository.save(categoria);
        return new CategoriaResponse(saved.getId(), saved.getNombre(), saved.getDescripcion());
    }

    public Categoria buscarEntidadPorId(Long id) {
        return repository.findById(id)
            .orElseThrow(() -> new ResourceNotFoundException("Categoría", id));
    }
}

Paso 8: Servicio MedicamentoService — CRUD completo

// src/main/java/com/universidad/farmacia/service/MedicamentoService.java
package com.universidad.farmacia.service;

import com.universidad.farmacia.dto.CreateMedicamentoRequest;
import com.universidad.farmacia.dto.MedicamentoResponse;
import com.universidad.farmacia.dto.UpdateMedicamentoRequest;
import com.universidad.farmacia.exception.ResourceNotFoundException;
import com.universidad.farmacia.model.Categoria;
import com.universidad.farmacia.model.Medicamento;
import com.universidad.farmacia.repository.MedicamentoRepository;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class MedicamentoService {

    private final MedicamentoRepository repository;
    private final CategoriaService categoriaService;

    public MedicamentoService(MedicamentoRepository repository, CategoriaService categoriaService) {
        this.repository = repository;
        this.categoriaService = categoriaService;
    }

    public List<MedicamentoResponse> obtenerTodos() {
        return repository.findAll().stream()
            .map(this::toResponse)
            .toList();
    }

    public MedicamentoResponse obtenerPorId(Long id) {
        var med = repository.findById(id)
            .orElseThrow(() -> new ResourceNotFoundException("Medicamento", id));
        return toResponse(med);
    }

    public MedicamentoResponse crear(CreateMedicamentoRequest request) {
        Categoria categoria = null;
        if (request.categoriaId() != null) {
            categoria = categoriaService.buscarEntidadPorId(request.categoriaId());
        }
        var medicamento = new Medicamento(
            request.nombre(), request.precio(), request.cantidadInventario(), categoria
        );
        return toResponse(repository.save(medicamento));
    }

    public MedicamentoResponse actualizar(Long id, UpdateMedicamentoRequest request) {
        var existente = repository.findById(id)
            .orElseThrow(() -> new ResourceNotFoundException("Medicamento", id));

        existente.setNombre(request.nombre());
        existente.setPrecio(request.precio());
        existente.setCantidadInventario(request.cantidadInventario());

        if (request.categoriaId() != null) {
            existente.setCategoria(categoriaService.buscarEntidadPorId(request.categoriaId()));
        }

        return toResponse(repository.save(existente));
    }

    public void eliminar(Long id) {
        if (!repository.existsById(id)) {
            throw new ResourceNotFoundException("Medicamento", id);
        }
        repository.deleteById(id);
    }

    private MedicamentoResponse toResponse(Medicamento m) {
        return new MedicamentoResponse(
            m.getId(), m.getNombre(), m.getPrecio(), m.getCantidadInventario(),
            m.getCategoria() != null ? m.getCategoria().getNombre() : "Sin categoría"
        );
    }
}

Paso 9: Controlador CategoriaController

// src/main/java/com/universidad/farmacia/controller/CategoriaController.java
package com.universidad.farmacia.controller;

import com.universidad.farmacia.dto.CategoriaResponse;
import com.universidad.farmacia.dto.CreateCategoriaRequest;
import com.universidad.farmacia.service.CategoriaService;
import jakarta.validation.Valid;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/categorias")
public class CategoriaController {

    private final CategoriaService service;

    public CategoriaController(CategoriaService service) {
        this.service = service;
    }

    @GetMapping
    public List<CategoriaResponse> listarTodas() {
        return service.obtenerTodas();
    }

    @PostMapping
    public ResponseEntity<CategoriaResponse> crear(@Valid @RequestBody CreateCategoriaRequest request) {
        var response = service.crear(request);
        return ResponseEntity.status(HttpStatus.CREATED).body(response);
    }
}

Paso 10: Controlador MedicamentoController — CRUD completo

// src/main/java/com/universidad/farmacia/controller/MedicamentoController.java
package com.universidad.farmacia.controller;

import com.universidad.farmacia.dto.CreateMedicamentoRequest;
import com.universidad.farmacia.dto.MedicamentoResponse;
import com.universidad.farmacia.dto.UpdateMedicamentoRequest;
import com.universidad.farmacia.service.MedicamentoService;
import jakarta.validation.Valid;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/medicamentos")
public class MedicamentoController {

    private final MedicamentoService service;

    public MedicamentoController(MedicamentoService service) {
        this.service = service;
    }

    @GetMapping
    public List<MedicamentoResponse> listarTodos() {
        return service.obtenerTodos();
    }

    @GetMapping("/{id}")
    public MedicamentoResponse obtenerPorId(@PathVariable Long id) {
        return service.obtenerPorId(id);
    }

    @PostMapping
    public ResponseEntity<MedicamentoResponse> crear(@Valid @RequestBody CreateMedicamentoRequest request) {
        var response = service.crear(request);
        return ResponseEntity.status(HttpStatus.CREATED).body(response);
    }

    @PutMapping("/{id}")
    public MedicamentoResponse actualizar(@PathVariable Long id, @Valid @RequestBody UpdateMedicamentoRequest request) {
        return service.actualizar(id, request);
    }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void eliminar(@PathVariable Long id) {
        service.eliminar(id);
    }
}

Paso 11: Carga de datos iniciales

// src/main/java/com/universidad/farmacia/config/DataLoader.java
package com.universidad.farmacia.config;

import com.universidad.farmacia.model.Categoria;
import com.universidad.farmacia.model.Medicamento;
import com.universidad.farmacia.repository.CategoriaRepository;
import com.universidad.farmacia.repository.MedicamentoRepository;
import org.springframework.boot.CommandLineRunner;
import org.springframework.stereotype.Component;

@Component
public class DataLoader implements CommandLineRunner {

    private final CategoriaRepository categoriaRepository;
    private final MedicamentoRepository medicamentoRepository;

    public DataLoader(CategoriaRepository categoriaRepository, MedicamentoRepository medicamentoRepository) {
        this.categoriaRepository = categoriaRepository;
        this.medicamentoRepository = medicamentoRepository;
    }

    @Override
    public void run(String... args) {
        var analgesicos = categoriaRepository.save(new Categoria("Analgésicos", "Medicamentos para el dolor"));
        var antibioticos = categoriaRepository.save(new Categoria("Antibióticos", "Medicamentos antiinfecciosos"));
        var vitaminas = categoriaRepository.save(new Categoria("Vitaminas", "Suplementos vitamínicos"));

        medicamentoRepository.save(new Medicamento("Paracetamol", 15.50, 100, analgesicos));
        medicamentoRepository.save(new Medicamento("Ibuprofeno", 22.00, 80, analgesicos));
        medicamentoRepository.save(new Medicamento("Amoxicilina", 45.00, 50, antibioticos));
        medicamentoRepository.save(new Medicamento("Vitamina C", 12.00, 200, vitaminas));
    }
}

Verificación: Comandos curl

# 1. GET todas las categorías
curl http://localhost:8080/api/categorias

# 2. POST nueva categoría
curl -X POST http://localhost:8080/api/categorias \
-H "Content-Type: application/json" \
-d '{"nombre": "Dermatológicos", "descripcion": "Para la piel"}'

# 3. GET todos los medicamentos
curl http://localhost:8080/api/medicamentos

# 4. GET medicamento por ID
curl http://localhost:8080/api/medicamentos/1

# 5. POST nuevo medicamento con categoría
curl -X POST http://localhost:8080/api/medicamentos \
-H "Content-Type: application/json" \
-d '{"nombre": "Loratadina", "precio": 18.00, "cantidadInventario": 60, "categoriaId": 1}'

# 6. PUT actualizar medicamento
curl -X PUT http://localhost:8080/api/medicamentos/1 \
-H "Content-Type: application/json" \
-d '{"nombre": "Paracetamol 500mg", "precio": 17.50, "cantidadInventario": 95, "categoriaId": 1}'

# 7. DELETE eliminar medicamento
curl -X DELETE http://localhost:8080/api/medicamentos/4

# 8. GET verificar eliminación
curl http://localhost:8080/api/medicamentos

# 9. GET medicamento inexistente (debe retornar 404)
curl -v http://localhost:8080/api/medicamentos/999

# 10. POST con validación fallida
curl -v -X POST http://localhost:8080/api/medicamentos \
-H "Content-Type: application/json" \
-d '{"nombre": "", "precio": -5, "cantidadInventario": -1, "categoriaId": 1}'

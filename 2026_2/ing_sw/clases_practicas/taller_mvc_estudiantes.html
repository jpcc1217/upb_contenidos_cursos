Taller Práctico: Construyendo un Sistema de Gestión Estudiantil (MVC)

Ingeniería de Software - FastAPI, SQLModel y Jinja2

1 Introducción

En este taller de 2 horas construiremos un Sistema Básico de Gestión de Estudiantes y Notas desde cero. Aprenderemos a implementar la arquitectura MVC (Modelo-Vista-Controlador) utilizando Python moderno.

Para lograrlo, utilizaremos las siguientes tecnologías: - FastAPI: Nuestro framework de backend (Controlador). - SQLModel y SQLite: Para la base de datos (Modelo). - Jinja2 y Bootstrap 5: Para generar nuestro frontend (Vista).

Al finalizar, tendrás una aplicación web funcional donde podrás registrar estudiantes, guardarlos en una base de datos real, y visualizarlos en una interfaz profesional.

2 1. Requisitos Previos e Instalación

Antes de escribir nuestro código, debemos preparar nuestro entorno de trabajo.

2.1 1.1 Verificación de Python

Abre tu terminal (o consola de comandos) y verifica que tengas Python 3.11 o superior:

python --version
# En Windows podría ser: python --version
# En Mac/Linux podría ser: python3 --version

2.2 1.2 Creación del Entorno Virtual

Para mantener ordenado nuestro proyecto, crearemos una carpeta y dentro de ella un entorno virtual. Ejecuta los siguientes comandos uno por uno:

En Windows:

mkdir mvc_estudiantes
cd mvc_estudiantes
python -m venv venv
venv\Scripts\activate

En Mac/Linux:

mkdir mvc_estudiantes
cd mvc_estudiantes
python3 -m venv venv
source venv/bin/activate

(Sabrás que funcionó si ves (venv) al inicio de tu línea de comandos).

2.3 1.3 Instalación de Dependencias

Con el entorno activado, vamos a instalar el “Stack” tecnológico que usaremos hoy:

pip install "fastapi[standard]" sqlmodel jinja2

Abre esta carpeta (mvc_estudiantes) en tu editor de código (como Visual Studio Code).

3 2. El Modelo (Base de Datos)

En la arquitectura MVC, el Modelo representa los datos y las reglas de negocio. Usaremos SQLModel, una librería que nos permite definir cómo serán nuestras tablas en la base de datos usando clases de Python.

3.1 2.1 Configuración de la Base de Datos

Crea un archivo llamado database.py y agrega el siguiente código. Usaremos SQLite, que creará un archivo .db en nuestra carpeta (no necesitamos instalar nada externo).

from sqlmodel import SQLModel, create_engine, Session

# Nombre del archivo SQLite local que se creará
sqlite_file_name = "universidad.db"
sqlite_url = f"sqlite:///{sqlite_file_name}"

# Configuración necesaria para usar SQLite con FastAPI
connect_args = {"check_same_thread": False}

# Creamos el "motor" de conexión. echo=True nos mostrará el SQL interno en la consola.
engine = create_engine(sqlite_url, echo=True, connect_args=connect_args)

def create_db_and_tables():
    """Función para crear las tablas en el archivo de la base de datos"""
    SQLModel.metadata.create_all(engine)

def get_session():
    """Generador de sesiones para conectarnos a la base de datos"""
    with Session(engine) as session:
        yield session

3.2 2.2 Creación de los Modelos de Datos

Crea un archivo llamado models.py. Aquí definiremos cómo es un Estudiante y una Nota.

from sqlmodel import SQLModel, Field, Relationship
from typing import List, Optional

class Estudiante(SQLModel, table=True):
    # La llave primaria se autogenera si no la enviamos
    id: Optional[int] = Field(default=None, primary_key=True)
    codigo: str = Field(index=True, unique=True)
    nombre: str
    semestre: int
    
    # Relación: Un estudiante tiene muchas notas
    notas: List["Nota"] = Relationship(back_populates="estudiante")

class Nota(SQLModel, table=True):
    id: Optional[int] = Field(default=None, primary_key=True)
    materia: str
    calificacion: float
    
    # Llave foránea que lo enlaza con la tabla estudiante
    estudiante_id: int = Field(foreign_key="estudiante.id")
    
    # Relación inversa
    estudiante: Estudiante = Relationship(back_populates="notas")

4 3. El Controlador (FastAPI)

El Controlador es el cerebro que conecta el Modelo con la Vista. Recibe las peticiones del navegador web, busca en la base de datos y envía HTML de vuelta.

4.1 3.1 Creación del Servidor

Crea el archivo main.py en la misma carpeta:

from fastapi import FastAPI, Request, Depends, Form
from fastapi.responses import HTMLResponse, RedirectResponse
from fastapi.templating import Jinja2Templates
from sqlmodel import Session, select
from contextlib import asynccontextmanager

from database import create_db_and_tables, get_session
from models import Estudiante

# Este código asegura que la base de datos se cree al encender el servidor
@asynccontextmanager
async def lifespan(app: FastAPI):
    create_db_and_tables()
    yield

app = FastAPI(lifespan=lifespan, title="Sistema Estudiantes MVC")

# Configuramos dónde estarán nuestras vistas (Jinja2)
templates = Jinja2Templates(directory="templates")

# Ruta para ver los estudiantes (GET)
@app.get("/", response_class=HTMLResponse)
def listar_estudiantes(request: Request, session: Session = Depends(get_session)):
    # Buscamos todos los estudiantes en la BD
    estudiantes = session.exec(select(Estudiante)).all()
    
    # Renderizamos la vista enviando los estudiantes
    return templates.TemplateResponse(
        request=request, 
        name="index.html", 
        context={"estudiantes": estudiantes}
    )

# Ruta para crear un estudiante (POST)
@app.post("/estudiantes/")
def crear_estudiante(
    codigo: str = Form(...),
    nombre: str = Form(...),
    semestre: int = Form(...),
    session: Session = Depends(get_session)
):
    # Creamos el modelo y lo guardamos
    nuevo_estudiante = Estudiante(codigo=codigo, nombre=nombre, semestre=semestre)
    session.add(nuevo_estudiante)
    session.commit()
    
    # Redirigimos al usuario a la página de inicio
    return RedirectResponse(url="/", status_code=303)

5 4. La Vista (HTML y Jinja2)

Para las vistas, usaremos un motor de plantillas llamado Jinja2. Esto nos permite inyectar variables de Python directamente dentro de código HTML. Además, usaremos Bootstrap 5 para que el diseño sea atractivo al instante.

5.1 4.1 Creando la Plantilla Base

Crea una carpeta llamada templates. Dentro de esa carpeta, crea un archivo llamado base.html:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{% block title %}Sistema de Notas{% endblock %}</title>
    <!-- Incluimos Bootstrap CSS -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light">

    <!-- Barra de Navegación -->
    <nav class="navbar navbar-expand-lg navbar-dark bg-primary mb-4">
        <div class="container">
            <a class="navbar-brand" href="/">📚 UniGestión</a>
        </div>
    </nav>

    <!-- Aquí irá el contenido dinámico de las otras páginas -->
    <main class="container">
        {% block content %}
        {% endblock %}
    </main>

    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

5.2 4.2 Creando la Interfaz Principal

Dentro de la carpeta templates, crea el archivo index.html. Nota cómo “hereda” del archivo base y usa un ciclo for de Jinja para mostrar los estudiantes:

{% extends "base.html" %}

{% block title %}Inicio - Estudiantes{% endblock %}

{% block content %}
<div class="row">
    <!-- Formulario para agregar estudiante -->
    <div class="col-md-4">
        <div class="card shadow-sm mb-4">
            <div class="card-header bg-success text-white">
                <h5 class="card-title mb-0">Agregar Estudiante</h5>
            </div>
            <div class="card-body">
                <form action="/estudiantes/" method="POST">
                    <div class="mb-3">
                        <label for="codigo" class="form-label">Código Estudiantil</label>
                        <input type="text" class="form-control" id="codigo" name="codigo" required>
                    </div>
                    <div class="mb-3">
                        <label for="nombre" class="form-label">Nombre Completo</label>
                        <input type="text" class="form-control" id="nombre" name="nombre" required>
                    </div>
                    <div class="mb-3">
                        <label for="semestre" class="form-label">Semestre</label>
                        <input type="number" class="form-control" id="semestre" name="semestre" min="1" max="10" required>
                    </div>
                    <button type="submit" class="btn btn-success w-100">Guardar</button>
                </form>
            </div>
        </div>
    </div>

    <!-- Lista de estudiantes (Tabla) -->
    <div class="col-md-8">
        <div class="card shadow-sm">
            <div class="card-header bg-dark text-white">
                <h5 class="card-title mb-0">Directorio de Estudiantes</h5>
            </div>
            <div class="card-body p-0">
                <table class="table table-hover table-striped mb-0">
                    <thead class="table-light">
                        <tr>
                            <th>Código</th>
                            <th>Nombre</th>
                            <th>Semestre</th>
                        </tr>
                    </thead>
                    <tbody>
                        <!-- Bucle Jinja2 para recorrer la lista enviada por FastAPI -->
                        {% for estudiante in estudiantes %}
                        <tr>
                            <td>{{ estudiante.codigo }}</td>
                            <td>{{ estudiante.nombre }}</td>
                            <td>{{ estudiante.semestre }}</td>
                        </tr>
                        {% else %}
                        <tr>
                            <td colspan="3" class="text-center text-muted py-4">
                                No hay estudiantes registrados. Usa el formulario para crear uno.
                            </td>
                        </tr>
                        {% endfor %}
                    </tbody>
                </table>
            </div>
        </div>
    </div>
</div>
{% endblock %}

6 5. ¡Ejecutar y Probar!

¡Hemos terminado el código! Ahora vamos a comprobar que nuestro sistema funcione.

  1. Asegúrate de estar en tu terminal y tener el entorno virtual activado.
  2. Ejecuta el servidor utilizando Uvicorn. Este es el comando estándar recomendado tanto para desarrollo local como para entornos como Docker:
uvicorn main:app --host 0.0.0.0 --port 6002 --reload

Deberías ver un texto en verde que indica que el servidor se levantó correctamente y que se creó el archivo universidad.db.

  1. Abre tu navegador web y visita: http://127.0.0.1:6002
  2. Prueba el sistema:
    • Observa que la tabla está vacía y muestra tu mensaje predeterminado.
    • Usa el formulario de la izquierda para agregar un estudiante.
    • Observa cómo, al hacer clic en “Guardar”, la página se recarga y tu nuevo estudiante aparece en la tabla.

¡Felicidades! Has creado un sistema web MVC completo desde cero.
